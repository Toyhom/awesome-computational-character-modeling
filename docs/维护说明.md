# 文献目录维护说明

仓库名称为 **Awesome Computational Character Modeling（计算角色建模）**，与综述标题 *Computational Character Modeling: A Survey of Role-Playing Agents from a Behavioral Science Perspective* 对应。

## 按论文结构查找目录

主页面沿用论文顺序：第三章方法、第四章数据、第五章评测。

- 方法：行为模仿、内部认知状态、经验与显式规则、情境互动、人格与价值特质、比较与综合。
- 数据：角色来源、角色信息与数据模态、数据构建与质量控制、规模与覆盖、数据支持的能力与建模局限。
- 评测：评测目标、测试设置、评分协议、评测可靠性与适用范围。评测目标下保留正文的四组讨论和 E1–E9；测试设置与评分协议下保留正文原有段落。

完整入口在[文献目录](../literature/README.md)。每一行都有可编辑 CSV、阅读页面和 BibTeX 下载。

## 添加新论文

1. 找到相关小类，打开对应 CSV。
2. 在该文件中添加一行完整元数据，包括题目、作者、年份、发表渠道、论文链接等。
3. 同一篇论文属于多个类别时，在各类别分别添加完整记录。不同类别的备注、资源链接、版本信息可以独立修改。
4. 在仓库目录运行：

```powershell
python scripts/build.py
```

README、详细文献页面、分类 BibTeX 和导出总表会同步生成。也可以直接在 GitHub 编辑分类 CSV，然后拉取到本地运行生成命令。仓库已准备好[自动更新工作流](../automation/README.md)，启用后即可在 `main` 更新时自动生成页面。

`id` 推荐使用作者、年份和短名称组成的引用键。已有论文可沿用同一个引用键，便于识别；生成器只禁止同一类别内部重复，不会合并、覆盖或同步不同类别的元数据。

## 修改显示文案或论文结构

- 修改介绍、贡献说明等固定文案：编辑 `templates/README.md`。
- 修改章节名称、顺序或小节位置：编辑 `catalog/structure.json`。
- 修改某一类别里的论文：只编辑该类别的 CSV。
- `README.md`、`literature/`、`exports/` 均为生成结果，直接修改后会在下次生成时被重建。

分类文件无需依赖原综述工作区；整个 `github` 目录可以独立使用。

## 校验

```powershell
python -m unittest discover -s tests -v
python scripts/build.py --check
```

校验会检查字段缺失、同类重复、链接格式和生成结果是否更新。不会要求跨类别记录一致。`exports/catalog.csv` 保留全部分类记录，包含同一论文在不同类别的多个条目。

初始文献来自投稿稿件正文和文献表，保留原引用归属；`source` 字段记录对应小节或表格。论文语料截止日为 **2026-07-16**，目录初始化日期为 **2026-11-02**。后续新增条目填写实际 `added` 日期。
